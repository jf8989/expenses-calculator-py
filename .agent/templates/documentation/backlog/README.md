# Documentation Backlog

This folder contains approved or otherwise decided product work deliberately deferred but still eligible for reactivation. It is opaque during normal discovery and is not an implementation queue.

Every backlogged document begins with:

```text
> Status: BACKLOGGED — <completed scope and remaining deferred scope>
> Backlogged: YYYY-MM-DD
> Reason: <why this is not active now>
> Reactivate when: <objective condition or explicit operator decision>
> Origin: <source and date>
> Approved: <approval history or not approved>
> Executed: <completed work and validation, or not executed>
```

Optional `Supersedes`, `Superseded by`, and `Validation` lines follow. Deferring an active plan moves its complete package under `backlog/plans/`, updates the documentation index and change log, and preserves provenance.

Reactivation requires an operator decision and a new or safely amended active master plan. Report a completed move as:

> Backlogged `<path>` on `<date>` — `<reason>`; completed: `<scope>`; remaining: `<scope>`; reactivate when: `<condition>`.
